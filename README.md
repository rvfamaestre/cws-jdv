# Enigma of Life

A puzzle game we made with Conway's Game of Life. Place the starting cells, run the simulation and try to reach the targets. Python and Pygame.

By Rafael Maestre López, Nils Malpot, Gabriel Sylvestre-Nunez, Louis Francois, Hugo Charles and Romain Chambon. Coding Weeks at CentraleSupélec, 2024.
